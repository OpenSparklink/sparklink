# 为什么按读者需求组织文档

[Diátaxis](https://diataxis.fr/) 区分教程、操作指南、技术参考和原理解释。
同一个主题可以分别出现于四类页面，但每篇有明确目的，并链接到其他类型，
避免同时教授、列参数、解释设计和记录整改历史。

对于 SparkLink，“如何在 VM 中测试两只 WS73”属于操作指南；
“generation、connection lifetime 和 fd 所有权有什么关系”属于原理解释；
“这个调用需要什么权限、返回什么错误”属于技术参考。
第一次引导读者从准备到可观察结果的过程，才适合写成教程。

实施计划和原始证据服务于项目管理与审查，不强塞进这四类面向使用者的文档。
站点给它们独立入口，保留失败、反例和尚未完成的条件。

本次首先调整导航和构建基础设施。现有架构、计划、资格及 ADR 仍是单一来源，
不复制成第二套权威文档。混合旧页面后续逐篇拆分；历史实机通过只适用于其明确
记录的源码和镜像，不能因页面进入新文档站就获得当前资格。
